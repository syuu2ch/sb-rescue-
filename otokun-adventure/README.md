# おとくんのぼうけん

3歳児向けのローカルPCゲームです。キーボードのどこを押しても、トラックパッドを触っても、おとくんが動物を集める冒険が進みます。誤操作でアプリが閉じることはありません。

## 起動方法

```
cd otokun-adventure
npm install
npm start
```

macOS上でElectronのフルスクリーン表示になります。

## 終了方法

**`Control + Shift + Q`** を押すとアプリが終了します。OSに直接登録されたショートカットなので、ゲーム画面のどこにフォーカスがあっても確実に効きます。
これ以外の操作（Cmd+Q、Cmd+W、ウィンドウを閉じる等）ではアプリは終了しません。

※ macOSのトラックパッドの複数指ジェスチャー（Mission Control切り替えなど）やCmd+Tab、Cmd+Spaceなど、OSレベルのショートカット/ジェスチャーはElectronアプリの範囲外のため完全にはブロックできませんが、通常どおり使えるはずです（Force Quitやアプリ切り替えでも脱出できます）。

## 遊び方

- 何かキーを押す、またはトラックパッド/マウスをクリックすると、おとくんが一歩ずつ画面を進んでいきます（押すたびに必ず反応します）。
- 数歩進むごとに宝箱が現れて開き、集めている動物のひらがなが1文字ずつ見つかります（読み上げ音声つき）。
- 単語が完成すると、おとくんが動物のもとへ駆け寄り、なかまになって一緒についてきます。
- なかまを3匹集めるごとに「とくちょうタイム」があり、集めた動物の特徴を教えてくれます。
- おとくんが画面の奥まで進むと、舞台が切り替わります（草原→森→海辺→雪山→夜空→おうち→ループ）。
- 「おうち」ステージではパパとママが登場し、時々リアクションします。
