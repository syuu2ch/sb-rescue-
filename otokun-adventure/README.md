# おとくんのぼうけん

3歳児向けのローカルPCゲームです。キーボードのどこを押しても、トラックパッドを触っても、おとくんが動物を集める冒険が進みます。誤操作でアプリが閉じることはありません。

## 起動方法

```
cd otokun-adventure
npm install
npm start
```

macOS上でElectronのフルスクリーン（kiosk）表示になります。

## 終了方法

**Option（⌥）キーを押しながら E → N → D の順にキーを押し、Option を離す**とアプリが終了します。
これ以外の操作（Cmd+Q、Cmd+W、ウィンドウを閉じる等）ではアプリは終了しません。

※ macOSのトラックパッドの複数指ジェスチャー（Mission Control切り替えなど）やCmd+Tab、Cmd+Spaceなど、OSレベルのショートカット/ジェスチャーはElectronアプリの範囲外のため完全にはブロックできません。

## 遊び方

- 何かキーを押す、またはトラックパッド/マウスをクリックすると、集めている動物のひらがなが1文字ずつ埋まっていきます（読み上げ音声つき）。
- 単語が完成すると、おとくんが動物のもとへ駆け寄り、なかまが増えます。
- なかまを3匹集めるごとに「とくちょうタイム」があり、集めた動物の特徴を教えてくれます。
- 画面上部のメーターが満タンになると、舞台が切り替わります（草原→森→海辺→雪山→夜空→おうち→ループ）。
- 「おうち」ステージではパパとママが登場し、時々リアクションします。
